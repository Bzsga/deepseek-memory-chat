获取 DeepSeek API Key

使用个人 Key 时，DeepSeek 按实际用量从你的开放平台账户扣费。

打开官方 API Keys 页面 ↗

1. 登录开放平台

点击上方按钮登录。也可以从 DeepSeek 官网选择「API 开放平台」进入。

查看官网入口图示

2. 确认余额，创建 Key

在「用量信息」确认余额，余额不足时按需充值。打开左上角菜单，选择「API keys」，点击「创建 API key」。

查看余额和创建按钮图示

3. 复制并回到应用保存

在创建成功窗口点击「复制」。完整 Key 只在创建时显示一次，请妥善保存。回到刚才的填写页面，粘贴个人 Key 并保存即可。

查看复制按钮图示
