## 本次更新

- 聊天页将账号入口集中到设置。从「多端同步」可以按需登录或注册，登录后返回同步设置，由用户确认是否开启同步。
- 管理员开启自助注册时，用户可免邀请码注册普通账号，获得基础云同步资格。已有账号也可兑换邀请码以获得对应的配套服务权限。管理后台可独立关闭自助注册。
- 聊天缺少可用 API 时，发送、编辑后发送或重试会直接打开「聊天 API」弹窗，并保留输入内容。
- 登录后可按需把访客会话复制到当前账号，原访客会话仍保存在本机。多端同步可分别选择聊天记录、聊天偏好和图片与附件原件。首次开启时默认同步聊天记录和偏好。
- 官网的固定下载链接根据更新清单跳转，实际安装包由 COS 提供。正式更新清单切换后，同一个链接即可获取新版本。
