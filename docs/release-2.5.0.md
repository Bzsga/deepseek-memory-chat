# DeepSeek 记忆聊天 2.5.0

Android（versionCode 36）、网页与后端使用同一版账号和设置协议。

- 免注册的本机访客可以使用个人 DeepSeek API Key 聊天，在当前设备查看记录、导入导出或从本机原文续聊。访客与各登录账号的聊天、设置和 Key 分别保存。兑换免费资格、同步到云端和创建公开分享时提示登录。
- 回复操作栏在朗读旁显示分享箭头，默认勾选本轮提问和回复，允许调整同一分支的其他消息，确认后才生成公开链接。尚无可分享回复的会话保留菜单入口。
- 侧栏和 Android 底栏共用设置中心，分为通用设置、数据管理和关于。Android 可以从相应分组打开本机整理服务、记忆备份与版本更新，再返回原分组。浏览器只显示当前可用的操作。
- 开发者入口仅对管理员账号显示。角色由服务端保存和验证。原生管理页面复用当前管理员的账号会话，直接访问网页管理地址需有管理员身份才能加载控制台。

## 验证范围

浏览器检验使用独立 Edge 环境、合成会话和模拟上游；分享按钮覆盖两轮问答的预选、改选与确认后创建。设置页面覆盖 320px 手机宽度、浏览器与新旧 APK 桥接，以及从原生返回对应分组。Android 桥接的浏览器检查用模拟握手，本轮没有实体手机交互测试。公开安装包按正式版本清单、签名及完整文件哈希核验。

访客测试覆盖个人 Key 聊天、文件和语音直连、本地导入导出、登录与退出后的资料隔离。管理员测试覆盖普通角色拒绝访问、管理会话随账号退出失效、旧共享口令失效。线上已验证保留管理员账号登录、管理接口权限和匿名管理页面。Android 11 模拟器验证本机设置返回、访客离线入口与管理权限切换，正式包使用原发行签名。部署回执为 `build/deployment.json`，下载核验见 `build/public-verification-2.5.0.json`。
