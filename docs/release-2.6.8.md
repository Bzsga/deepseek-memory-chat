# DeepSeek 记忆聊天 2.6.8

Android 2.6.8，versionCode 46。用户可见说明见 [更新记录](../CHANGELOG.md)。网页及后端部署为 `20261119T154054Z-0faff1`。

- 回复语气从下一次聊天请求开始生效。已有自定义文字迁移为「自定义」，切换预设保留文字。选中「模型默认」时不追加语气指令。
- 账号与邀请码可分别配置配套聊天 API、配套生图 API 和云同步。旧账号及邀请码沿用原授权。配套聊天与生图继续共用周额度，云同步由用户启用。撤回某项权限后，服务端拒绝后续依赖该权限的调用。
- 待查看反馈由服务器在北京时间每天 12:00 检查。只在 `pending` 数量大于零时向 Server 酱提交提醒，使用独立于网页和 APK 的定时服务。见 [反馈处理流程](feedback.md)。
