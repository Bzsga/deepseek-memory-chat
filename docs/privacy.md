# 隐私与数据说明

本说明对应 DeepSeek 记忆聊天网页、后端与 Android 2.6.0。自行部署或使用个人 API 时，实际服务运营者与上游模型服务商还有各自的数据政策。

## 本机持久资料

Android 原生记忆使用应用私有数据库，保存导入原件、聊天消息、记忆档案、修订历史和整理进度。应用内聊天使用 WebView 的 IndexedDB；网页版使用当前浏览器的 IndexedDB，按登录账户隔离。聊天正文、会话分支、续聊背景和生成图片原件在本机长期保存。聊天设置提供默认关闭的多端会话同步。

图片可点击进入全屏预览，长按或右键打开菜单。Android 选择“保存到相册”会将原始图片复制到系统相册 `Pictures/DeepSeek/`，系统相册和获授权的应用可读取该副本。Android 10 及以上写入应用自己创建的媒体，Android 8/9 按需申请存储写入权限。保存过程在本机完成。

导入、查看、编辑、选择原话、原文接续、复制和备份不调用模型。“在这里继续聊”只创建带背景的本地会话，用户输入并发送下一句话后才请求模型。

原生记忆工具由手机直接匿名读取 DeepSeek 公开分享接口。聊天首页的分享续聊使用已登录的同源服务转读固定公开接口，后端仅向 DeepSeek 发送分享 ID 与普通读取头，不转发账户凭据或模型密钥，响应不持久存到服务器。读取后先预览，确认才保存原始分享快照与消息到当前账户的本机资料；取消不会导入。持有分享链接的人也能查看，私密或完整记录可改用 ZIP/JSON 文件。外部文件通过系统授予的 `content:` URI 权限读取，不申请全盘访问。

## 可选多端会话同步

拥有免费资格的账号可开启多端同步，默认关闭。启用时选择会话和附件、聊天偏好中的至少一项。所选资料通过 HTTPS 同步并保存在服务器的受限私有数据库中，其他设备登录同一账号后可访问。会话包括消息、分支、会话记忆、续聊和分享来源，以及本机可用的图片和附件原件。未完成的模型任务仍由原设备恢复。

启用会话同步后，编辑、重命名、删除及备份恢复产生的会话变更会传播到同账号其他设备。两端同时修改时保留冲突副本。取消勾选某项会暂停该类同步，保留已有云端副本。同步操作使用 0 次模型额度。

关闭同步或取消免费资格会停止上传和读取，云端副本持续保留。账号仍可在设置中清除云端副本，该操作同时关闭同步并清除服务器中的同步内容，本机资料保留。设备中已下载的副本和另行导出的备份由相应设备或持有人保管。公开分享仍可在分享管理中撤销。同步范围与接口见[多端会话同步](conversation-sync.md)。

## 创建公开分享

用户在会话菜单选择消息并创建分享时，所选正文、图片原件和附件名称、大小、类型会上传到本项目服务器，保存为创建时的公开副本。该副本持续有效，直到创建者撤销。持有链接的人可匿名读取，也可在本应用中预览并确认导入。分享不包含思考、工具动作、系统上下文、记忆或未选中的分支，创建和导入均不调用模型。

设置中的数据管理可查看并撤销自己的分享，即使本机会话已经删除。撤销会清除服务器中的正文和图片，后续链接读取返回不可用，仅保留最少撤销记录以处理重复请求。已经被他人导入、下载或截图的副本由接收者保管。本机删除、清除资料和卸载操作不会自动撤销服务器分享。分享预览在确认前只读，确认后才将原文、来源快照和图片追加到当前账户的本机资料。详见[会话分享](conversation-sharing.md)。

## 账户、密钥和备份

配套聊天与免费智能整理需要注册登录。服务器保存用户名、加盐密码摘要、会话摘要、注册/邀请码信息、额度与调用元数据。后台展示注册用户及用量，不提供日常聊天正文列表。

Android 原生账户会话与原生整理所需的 API Key 使用 Keystore 保护的加密存储。聊天用的个人 DeepSeek Key 保存在当前设备的本机加密存储中，访客与每个账号分别保管。浏览器使用不可导出的 WebCrypto 密钥和 AES-GCM 保存密文，运行时向用户选择的 HTTPS 服务提供对应 Key。Android 通过应用内通道将当前聊天配置交给同账号的原生整理工具。启用云同步会同步常用聊天偏好。用户可另外设置恢复口令，备份聊天用的个人 Key。设备在本机加密，服务器只保存密文、随机盐和 IV。换设备后需手动输入口令恢复。清除云端数据会删除此备份。应用账号登录使用 Secure、HttpOnly、SameSite Cookie。退出登录保留本机资料。

自助注册开放时，用户可以创建普通账号并自行开启多端同步。获得相应权限的账号可以使用配套免费服务。访客可使用自己的 Key。个人模式下，聊天、自动上下文整理、文件、语音识别和朗读由用户选定的 API 服务计费。图片生成使用独立个人生图配置或有效的配套服务，个人生图按所选服务计费。Key 设置按设备保存，会话同步、导出与公开分享使用各自的会话字段白名单。用户可在聊天设置中切换服务、替换或清除个人 Key。[个人 DeepSeek API](personal-deepseek.md)

聊天 ZIP 和记忆备份是不同入口，应分别保存。备份含私人聊天、记忆、来源或图片原件，应视为敏感文件；不含密码、API Key 或账户/管理员会话。恢复会在确认后替换对应本地资料。卸载、清除应用数据或清理浏览器存储可能删除尚未备份的内容；清除本机资料不会删除已另存、分享或发送给外部服务的数据。

## 发送到模型的内容

在同一会话点击发送时，自动上下文管理会选择近期原文、相关旧原文、续聊背景与适用的本地记忆。需要压缩较早原文时，一次发送最多先增加一次整理请求，再请求聊天回复；整理也发送到相同已配置模型，经同一后端正常计次。界面显示整理状态和额外调用，用户可查看、编辑、固定、删除或关闭会话记忆。该过程不要求另开窗口或每次手动确认。

原文和派生记忆保存在本机，后端聊天账本不保存摘要或原文。完整历史不会在每次请求中无限累积；选取和摘要可能遗漏细节。失败或结果不确定的自动整理片段不会自动重发，系统会显示受限状态并用预算内原文继续。分支或原文发生变化后，失效来源的记忆不会作为当前聊天背景。

- **聊天、附件和语音**：当前文字、所需历史、续聊背景及显式附件经后端转发给聊天上游；录音转写和文字朗读分别发送相应内容。后端调用账本只保存身份、时间、类别、状态和计次等无正文信息，以及附件归属，不持久保存这些聊天、录音或附件字节。
- **图片生成**：使用个人生图配置时，设备直接向所选服务发送提示词和对应 Key。使用配套服务时，绘图提示词经后端发给生图服务。普通聊天中，模型响应明确绘图需求，根据本轮上下文形成实际提示词并调用生图工具，聊天与生图分别按实际派发计次。原始生图动作记录与实际提示词保存在本机及结构化备份中。为支持切屏、网页重建后取回结果，服务器在私有目录临时保存生成图片与模型信息，24 小时到期清理，领取需要登录同一账户。提示词仅在生成进程内存中使用，任务元数据保留其摘要、账户、稳定请求编号和状态。图片取回后保存在本机。切屏和网络断开不会重新提交或重新扣次。结果不确定的上游请求不会自动重发。后续历史标明实际生成状态与提示词，模型看图仍需显式添加图片附件。
- **编辑图片**：点发送后，应用把选择的原图和修改要求交给当前生图服务。配套服务仅在处理任务时把原图放在进程内存，任务记录保留请求摘要，编辑结果按同样规则暂存。原图作为该条消息的附件保存在本机，和其他附件一样受会话导出、分享及同步设置控制。
- **智能整理**：发送用户选择的原话和必要的已选前段参考。配套服务使用异步任务，暂存选段与结果以支持进度查询和恢复；终态 24 小时后清理正文与结果。任务编号、内容摘要、状态、幂等和计次元数据继续保留。服务停机期间到期内容会在恢复后清理。
- **自己的 API**：Android 直接请求用户配置的 HTTPS 服务商，发送所选内容和必要参考；不经过本项目整理后端，由服务商计费并适用其政策。

独立的原生“整理记忆”工具先在手机保存当前选中分支并打开准备页，不立即请求模型；选择智能整理并明确开始后才上传选段。该手动工具与聊天中的自动上下文管理分别运行。用户文字和助手正文按原样提取，不包含思考和工具过程。

## 可选敏感内容检查

“去除敏感内容”检查当前续聊导出文本。打开入口只准备范围，点击“开始检查”后才发送相应分段并正常计次或计费。它只标记可能涉及政治敏感议题的原文片段与原因，用户可保留误判；不会改写原档案，也不自动清理个人信息或保证外部平台接受。

检查快照、进度和保留选择存于当前设备，不纳入普通记忆备份。配套模式同样适用整理任务的临时正文与诊断留存规则。

## 失败诊断、反馈与上游

整理失败或结果不确定时，可按服务配置另存必要请求快照和有界原始回复，默认保留 24 小时，自托管可关闭或设置期限。它们可能含私人原话和上游推理字段；剔除已知服务密钥，不保存鉴权头，没有公网读取接口，只供受限运维按编号排障。成功整理不额外新增此副本。过期拒读并清理，缺失或截断会明确标记。详见[失败诊断](failure-replay.md)。

手机技术诊断只接受受限的版本、设备、处理阶段、大小/耗时和异常位置等白名单元数据，不接受自由正文；服务端保留 30 天。用户主动提交反馈时上传所选文字、联系方式和图片，适用[反馈说明](feedback.md)。普通 BYOK 使用不会为同步聊天而上传资料，独立反馈或诊断交互按其说明处理。

服务器的清理机制不控制上游服务商或用户另行制作的备份。不要向公开 Issue 或普通日志粘贴聊天原文、诊断正文、备份、密钥或登录凭据。
