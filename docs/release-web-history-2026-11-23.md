# 会话与资料网页更新

2026-11-23 13:54（北京时间）已发布到官网。网页和 Android 2.6.24 使用同一聊天页面。 [打开聊天](https://digimonlegend.com/deepseek/) · [更新记录](https://digimonlegend.com/deepseek/changelog.html)

## 本次更新

- 侧栏可按本机会话标题和消息正文搜索，会话内也可查找并跳到旧消息或对应分支。
- 回到同一会话可恢复上次阅读位置。未发送的文字按设备和工作区保留，刷新后可以找回。
- 「设置 → 数据管理 → 添加旧聊天」可预览并勾选兼容的历史 ZIP 或本应用单会话 JSON。追加保留本机同 ID 会话，单次选中内容解压后最多 64 MiB。整库恢复有独立入口。
