# DeepSeek 记忆聊天 2.6.10

Android 2.6.10，versionCode 48，于 2026-11-20 18:50（北京时间）发布。配套网页部署为 `20261120T103558Z-1662ea`。用户可见说明见[更新记录](../CHANGELOG.md)，线上分发状态见[更新清单](https://digimonlegend.com/continuation-updates/latest.json)。

- 管理员可在「开发者工具 → 用户与邀请码 → 全局功能开放」分别开启配套聊天 API、配套生图 API 和云同步。点「保存开放设置」提交，关闭某项后恢复按账号权限判断。
- 读取失败时可以从该区块重新读取。保存结果不明时先读取服务端状态，再重新编辑。
- APK 已核对正式签名、包名、版本和 SHA-256。Android 管理接口定向测试及后端全局权限定向测试通过。
- Android 11 模拟器通过窄屏开关操作测试，覆盖首次读取失败后的重试、独立勾选和保存前后的状态。使用正式签名包从 2.6.9 覆盖升级至 2.6.10 成功。
- 「个人生图 API」支持 Android 原生 HTTPS 直连。模型列表、文生图和多张参考图编辑使用用户配置的服务与凭据。网页版和旧 APK 继续使用浏览器请求，需要服务商开放跨域访问。
- 个人生图的网页构建和桥接回归通过。模拟 HTTPS 服务验证了多图提交、独立下载结果、取消及失败时仅发送一次生成请求。Android 11 模拟器的三项桥接测试通过。
- 公网更新清单和官网下载安装入口已切换到 48。版本化 APK 经主站跳转到 COS，整包 SHA-256 与正式签名包一致，分段请求返回 HTTP 206。
