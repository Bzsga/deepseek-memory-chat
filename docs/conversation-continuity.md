# DeepSeek 记忆聊天的续聊流程

DeepSeek 记忆聊天 2.2.0 默认在同一会话中持续交流。聊天使用网页界面，聊天原文、上下文记忆与原生档案分别保存在当前设备。

## 同一会话自动续聊

每次发送优先选择近期完整轮次，再按预算带入有效记忆、相关旧原文和续聊背景。当前自动使用 936,000 的保守估算输入预算，对 1M 窗口预留 64,000 回复与协议余量，旧档位读入时迁移。参数由应用管理，用户可直接聊天。上下文有实际上限，自动选材和摘要可能遗漏细节。

需要时自动将一个较早原文片段整理为带来源的记忆。每次发送最多增加一次整理请求，正常消耗共享次数，界面显示活动和额外调用。整理依赖独立原文片段，不层层概括旧摘要。失败或结果不确定的片段不会在下次发送时自动重放，聊天仍可使用预算内的原文继续。

全部原文和分支继续保存。来源消息标识与内容指纹用于核对记忆是否仍适用。编辑、切换分支或账户后，不接收过时结果。会话菜单可查看、编辑、固定、删除记忆或关闭自动记忆，预算由应用管理。用户可在原会话持续交流。

## 添加旧聊天与恢复备份

「设置 → 数据管理 → 添加旧聊天」预览本应用的会话 JSON 或兼容的历史 ZIP，选择会话后追加到本机。已有同 ID 会话保留本机版本。缺失或损坏的选中内容会阻止本次写入。需要整体替换时，请选「恢复整库备份」，在确认页核对备份和本机聊天数量。

每次追加的选中会话及其附件解压后合计最多 64 MiB。选中的内容较多时，可分次添加。

## 导出会话

会话菜单提供 Markdown、纯文本、JSON 和 ZIP。Markdown/文本导出当前分支，便于阅读；JSON/ZIP 保留整个消息树、图片附件与生成图片原件、续聊背景和长期记忆，其他附件仅保留元数据。单会话 JSON 最多 32 MiB，更大资料请使用 ZIP。结构化文件可通过聊天资料入口导入，全库 ZIP 备份仍可使用。Android 通过系统保存窗口选择位置。

## 从当前聊天整理记忆

原生记忆工具保留外部资料导入与独立档案整理。将聊天交给原生工具时，App 读取当前选中的消息分支，保留用户发言、助手正文和消息标识，再进入选择与准备页面。选择范围和开始整理由用户确认。

所选内容在 1–30 条、正文总长不超过 6000 字符且含非空正文时，准备页默认使用完整原文。长度按原始正文计算，空白也计入。用户可选择智能整理，较长聊天支持分段整理并保存进度。

DeepSeek 分享链接也可作为原文来源。新对话页可粘贴链接，查看两张复制链接教程图，读取后预览消息和分享范围，确认后新增本机会话。原始快照、来源链接、角色和分支会随结构化备份保存，当前选定分支进入后续上下文。分享中的附件缺少原件时需重新上传。私密或完整会话可使用 ZIP/JSON 文件导入，也可手动粘贴聊天内容。

## 原话与自然回顾

整理尽量保留原话、具体经历、纠正、条件、犹豫和未定事项，优先去除重复内容。回顾使用用户的“我”、对话伙伴的“你”和双方的“我们”，第三人和假设保留各自归属。

记忆条目保存所依据的消息来源。用户可以编辑、固定、删除条目，选择关键原话，调整希望延续的交流方式。自动选材参考明确的当前要求、近期原话和已选来源。摘要预览默认展开，详细编辑、敏感内容处理和重新整理位于工具面板。

历史停点作为回顾背景。接续时以用户当前发来的话为依据，可以自然重新进入交流，保留原对话的语气和未确定之处。

## 在这里继续聊

档案结果页的“在这里继续聊”使用当前预览对应的完整续聊文本，在聊天页新增一个空会话。该会话把资料持久化为专门的 `continuity` 背景，保存标题、原文和来源档案标识。携带动作完成后，用户可查看背景并输入下一句话。

后续聊天按上下文预算从这份背景中选材，较大的背景不会绕过预算整段反复附带。消息树保存真实的新发言与回复。用户主动发送下一句话时才开始模型请求。聊天记录与备份包含完整背景，原生档案继续提供编辑和重新选材入口。

结果页同时提供复制、保存文件和外部接续操作，实际文本与当前预览一致。

## 补入最近聊天与更新来源

带着记忆新建的聊天保存 `sourceArchiveId`。再次点击“整理记忆”时，这个标识随当前分支原文传回 App。对应档案存在时，App 进入补入最近聊天的流程。

补入依据会话、分支、消息标识和正文核对已有覆盖，保留本轮可确认的新增原文。用户可先保存原文，再开始增量整理。分段任务以完整消息证据判断已完成范围。

重新整理生成一份关联原档案的新版。人工编辑、固定条目、删除标记和补充背景参与保护，新建议与人工内容重叠时进入冲突核对。任务保存已完成进度和原请求身份，恢复操作继续已有工作。

## 本机资料与使用次数

原文、记忆档案、聊天和附件原件保存在当前设备。智能聊天、附件上传、语音、生图和免费智能整理共用账号的每周次数，北京时间每周一零点刷新。模型操作的确认页或入口显示相关消耗，长文整理按实际派发的请求累计。

本地导入、预览、编辑、原文接续、复制和备份可直接使用。原生智能整理支持自己的 API，凭据存放于 Android 加密存储。使用免费模型服务需要注册登录。

多选管理支持逐条选择、全选和确认删除。删除档案时会处理所关联的本地整理任务。重要资料可通过设置页备份，聊天页也提供本机聊天历史导出。

接口及本机消息通道见[契约说明](contracts.md)，服务部署见[后台说明](backend.md)。
