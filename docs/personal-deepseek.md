# 个人 DeepSeek API

聊天设置可选择配套服务或个人 DeepSeek API。首次发送聊天时若缺少可用 API，可直接打开聊天 API 配置并保留消息草稿。访客也可以使用个人 API。管理员开放自助注册时，新用户可创建具备基础云同步资格的账号，并按需填写或兑换邀请码获得其他权限。有配套聊天权限时默认使用配套聊天服务。管理员可分别管理配套聊天 API、配套生图 API 和云同步。个人模式默认使用 DeepSeek 官方 HTTPS 接口与 deepseek-flash 模型，聊天、自动上下文整理、文件、语音识别和朗读由个人 API 账户计费。账号、会话同步与分享继续使用应用账号。

个人聊天 Key 按设备及工作区单独保存。访客无需注册即可填写自己的聊天 Key，登录后使用该账号独立的资料和凭据。使用独立的本机加密存储，运行时向用户选定的 HTTPS 服务提供相应凭据。会话同步、会话导出和公开分享只处理其定义的会话数据。开启多端同步后可单独备份加密的聊天 Key。换设备时输入恢复口令即可还原。忘记口令时可重新填写 Key。

官方个人请求复用现有 Messages/SSE 和工具解析，使用 credentials omit、固定官方路径和受限鉴权头。个人 Key 错误与应用账号登录失效分别处理。切换服务或替换 Key 时隔离文件上游 ID 与上传缓存，按其所属服务重新上传可用原件。每次请求固定其使用的服务和 Key。

保存配置使用本机操作。真实模型请求由正常聊天等用户操作触发。DeepSeek 官方 Key 的权限和余额由 DeepSeek 决定。

在聊天设置的高级选项中填写兼容服务的 HTTPS Base URL，再点击「获取模型列表」并选择模型，或直接填写模型 ID。自定义聊天使用 `chat/completions`，服务需支持浏览器跨域访问。聊天 Key 的口令备份会同时保存目标地址与模型。

回复偏好顶部可选择基础风格、回答详略和回应方式。基础风格支持预设和自定义。回答详略控制展开的程度，回应方式可侧重给建议、比较取舍或梳理问题。展开「表达细节」可继续调整语气和排版。同一方面的明确设置优先于基础风格，从下一次普通聊天请求起生效。「生成参数」中的温度影响输出的随机程度，关闭深度思考时生效。开启深度思考时使用所选思考强度。留空时使用供应商默认值，第三方模型对参数的支持以供应商为准。

## 个人生图 API

打开「设置 → 生图服务」，选择「个人生图 API」，填写服务商的 HTTPS Base URL、个人 API Key 和生图模型，再保存。可以点「获取模型列表」选择模型，也可以直接填写模型 ID。访客和已登录用户都可以使用个人生图，费用由所选服务商结算。选择「配套免费生图」时，需有账号的配套生图权限且服务器已启用该服务。

支持原生直连的 Android App 直接从设备获取模型列表、生成及编辑图片，服务商无需启用浏览器跨域访问。网页版和旧 APK 仍需服务商允许跨域访问。个人 Key 加密保存在本机，调用时只发给配置的服务商。图片请求失败后由用户决定是否重试，个人模式始终使用已配置的服务。服务商若返回 HTTPS 图片地址，下载图片时使用独立的无凭据请求。

使用「参考图」或「编辑此图」需要服务商的 `images/edits` 接口及所选模型支持图片编辑。发送后，选中的图片和修改要求直接提交给配置的服务商。可选至多 4 张 JPG、PNG 或 WebP，每张最多 12 MiB、合计最多 24 MiB。提交多张图片还需要服务商支持多图输入。

## 当前核验依据

官方资料支持 Messages、搜索与读链接、Files、ASR 和 TTS，同类 DeepSeek API Key 用于这些接口。deepseek-flash 支持图片输入。Android 2.6.2 开始，新建的记忆整理任务直接使用同账号的聊天 API。个人模式复用 Key、服务地址与模型，配套模式共用账号额度。已创建任务沿用原有配置。

2026-11-18 对官方 api.deepseek.com 的 Messages、Files、ASR、TTS 路径进行了无凭据 OPTIONS 检查。四个路径均允许应用 HTTPS 来源、POST 和所需 Authorization/Content-Type/anthropic-beta 头。该检查使用 0 次模型请求。
