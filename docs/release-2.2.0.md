# 2.2.0 发行记录

2026-11-17 已发布 Android、网页和后端 2.2.0，Android versionCode 31。本版包含后台生图恢复、自动上下文预算、分享链接续聊、关于页和语音输入修复。

## 改动

- 后台生图已先通过网页与后端 2.1.2 上线。页面销毁后按原任务编号恢复，实际生成计次一次，结果临时保留 24 小时。详见 [后台修复记录](release-web-2.1.2.md)。
- 上下文由应用按当前 DeepSeek 1M 窗口自动管理，采用 936,000-token 保守估算输入预算，预留 64,000 回复与协议余量。旧 32K/64K/128K 档位读入时迁移，普通会话记忆面板移除手动选择。Token 使用 UTF-8 字节数估算，超过窗口时仍需选材和必要压缩，完整原文继续保存在本机。预算本身不增加调用次数，实际携带的历史增加会提高上游输入 token 消耗和延迟，自动整理请求按正常调用计次。模型窗口和计费依据为 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/)。
- 新对话页提供分享链接读取、范围预览和导入继续入口，并提供用户给定的两张复制链接教程图。
- 聊天设置增加“关于该软件”，将作者署名集中在其中。原生关于页同步作者半盏丶时光、QQ 1076755135、由GPT-6制作，以及基于 DeepSeek 官方开源 chat-demo 修改的声明。
- 语音输入按设备实际采样率采集，再在本机转换为 16-kHz 单声道 PCM16 WAV。启动、麦克风权限、空录音与服务错误分别显示，取消会释放音轨和音频上下文。后端继续支持 WAV 与 Ogg Opus，校验通过后才派发计次。原固定 16-kHz AudioContext 和被忽略的恢复错误存在设备兼容缺口，用户手机上的具体失败环节仍缺少直接日志。

## 验证与发布

- 网页最终类型检查、lint、生产构建与差异检查通过。自动预算迁移、分享导入来源与选定分支、删除/导入/退出账户竞态、原文导出、后台生图恢复的定向回归通过。
- 后端相关 76 项测试通过，包括聊天与语音 55 项、分享读取 17 项、图片任务 4 项。录音转换 11 项检查通过，浏览器模拟麦克风已覆盖 48-kHz 采集到 16-kHz WAV 转换和资源释放。
- 分享与关于页生产包 UI 检查通过，独立视觉检查覆盖 23 张窄屏与短视口截图。读取预览不写入，确认后新增会话并保留原有会话，教程图正常加载，访客进入登录流程。官方分享读取路由从服务器可达，未提供有效的真实分享链接进行线上导入验证。
- 真实后台生图已用一次生成验证页面销毁后恢复，显示有效 1024×1024 图片，唯一 image 调用成功且只扣 1 次。该证据与账户、任务和临时结果清理记录见[后台修复记录](release-web-2.1.2.md)。
- 真实语音识别通过正常录音按钮、合成麦克风输入验证。设备 48-kHz 采集转换为 16-kHz 单声道 PCM16 WAV，5.888 秒、188,460 字节，唯一 file 字段提交一次 ASR，HTTP 200 返回“你好，这是语音识别测试。你好，这是语音识别测试。”并原样填入输入框。短合成音频在 6 秒采集期间循环，重复句子来自输入素材。服务器唯一 asr 调用成功，额度 35→34，录音轨道结束、AudioContext 关闭，临时账号和 profile 清理，公共注册计数保持 1。证据为 `build/qa/asr/asr-live-summary-v2.json` 和对应 browser 报告，complete=true，model_retries=0。
- Android assembleRelease 与 lintRelease 通过。没有连接用户手机，尚未直接覆盖该手机的麦克风硬件、系统权限提示及 WebView 生命周期。
