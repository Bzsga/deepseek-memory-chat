# 网页与后端 2.1.1 修复记录

修复对应用户 2026-11-17 的手机录屏与截图。网页与后端 2.1.1 已在线发布，Android 使用 2.1.0 / code 30。

## 范围

- 导出弹窗内容消失、下载按钮越出白卡的布局修复，并提供导出原文及跳转原生智能整理准备页的选择。
- 同身份的焦点和前后台登录检查保留当前聊天界面，首次点击侧栏能立即生效。明确过期或切换身份仍结束原账户会话。
- 生图请求增加可选 SSE 初始响应与周期保活，前端从结果事件读取图片，断流显示结果未确认并允许手动重试。每次发送仍只派发一次。

## 排查与验证

服务端最近两次手机生图请求记录为客户端断开后的 aborted，分别约 30.81 秒和 5.31 秒，没有上游生图 HTTP 错误记录。无响应等待期间的中间连接超时是本次保活修复的依据之一，尚不足以确定两次中断的全部原因。

- 弹窗受控故障先复现了白卡 44px、正文 0、底部操作越出卡片的几何形态。修复后正文和按钮完整位于卡内，320×708、360×430、390×780 通过。页面先取得 708px 后，将全部高度读数设为 0，再首次挂载弹窗，也能从共享记录取得 708px。实际手机的底层触发机制仍属几何吻合推断，未获取该设备 WebView 调试信息。
- 导出四种格式实际下载，智能整理交接保留两条原文和稳定消息 ID。原生桥 ACK 成功关闭面板，拒绝保留并提示；生成期间关闭整理跳转，原文导出可用。证据位于 `build/qa/modal-export/`。
- 录屏抽帧核对了首次触摸出现登录确认的过程。真实 Edge 生产页面在认证响应悬挂时，单次触摸打开侧栏，草稿及正在进行的请求保持；临时网络错误、恢复前台和 BFCache 检查通过。401、身份或角色变化仍停止活动并重新加载。证据位于 `build/qa/sidebar-fix/`，回归入口为 `web/scripts/check-session-refresh.mjs`。
- 原 JSON 生图路径 31 项与新增 SSE 6 项后端测试通过。检查初始响应先于延迟结果、周期保活、只计一次、流错误、断连回收、ASGI 2.4 发送失败、账户撤销和整体截止时间。前端类型、lint、构建、会话导出/SSE 读取和认证刷新检查通过。共享视口变更后的访客/登录零高度回归通过，证据位于 `build/qa/viewport-2.1.1/`。
- 线上使用隔离注册账户，安装 HttpOnly Cookie，从正常网页“画图”按钮仅提交一次合成提示词。2.18 秒开始收到数据，最大数据间隔 5.42 秒，8.05 秒时触发焦点并打开侧栏，123.75 秒时实际显示有效 1024×1024 图片。服务端唯一调用为成功，额度减少一次，临时账户、邀请码及浏览器 profile 已清理。原报告保留在 `build/qa/image-browser-smoke-2.1.1.json`，合成页面截图为同名 `-synthetic.png`。
- 本次浏览器脚本原始总体标记为失败，因为完整 `result` 后生产 SSE 读取器提前结束并主动 `reader.cancel()`，CDP 将其记录为 `net::ERR_ABORTED`。已显示的完整图片、解码尺寸与成功计次均保留在原报告。该结束条件的独立复核见 `build/qa/image-browser-smoke-2.1.1-assessment.json`，保留原始标记且未重复生成。
- 有限独立视觉复查覆盖导出和同类弹窗，导出布局及整理入口达到本次目标。设置面板的 24px 横向溢出随后按所发现负边距修复，最新定向检查正文/滚动宽度均为 312px。报告位于 `build/qa/visual-review-2.1.1/review.md`。
