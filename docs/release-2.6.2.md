# DeepSeek 记忆聊天 2.6.2

Android 2.6.2，versionCode 40。

- **记忆整理与聊天共用 API。** 新任务直接读取当前账号的聊天配置。个人模式使用同一个 Key、地址和模型，免费模式使用同一个应用账号的配套额度。已经创建的任务继续使用自己的服务快照。
- **版本与更新。** 当前版本与检查按钮置顶。发现更新后可看到发布日期、安装包大小、下载进度与更新说明。「关于」页提供源代码和反馈入口。
- **开源。** Android、网页和后端的源码以 MIT 许可证发布。教程中保留了文字步骤和可公开的示意素材。[GitHub 源码](https://github.com/Bzsga/deepseek-memory-chat)

官网的 Android 下载与推送状态以[更新清单](https://digimonlegend.com/continuation-updates/latest.json)为准。
