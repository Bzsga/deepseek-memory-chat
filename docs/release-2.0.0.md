# 2.0.0 / Android 28

2026-11-17，聊天、续聊记忆和管理后台合并为一个产品。聊天、智能整理、附件、语音与生图使用同一账户的每周次数，北京时间周一 00:00 刷新。普通聊天与本地记忆的长期记录留在设备；显式智能整理任务的上传选段和结果按临时任务机制在 24 小时后清理。
