# DeepSeek 记忆聊天 2.6.3

Android 2.6.3，versionCode 41。

- 「多端同步」支持分别选择会话和附件、聊天偏好。个人 API Key 备份收在「同步设置」内，需要单独设置恢复口令。
- 聊天和生图的个人 API Key 输入框直接显示新输入的字符。
- Android 聊天 WebView 在支持 `contentSensitivity` 的系统上退出自动录屏遮挡。设备厂商的录屏效果需在目标设备验证。

官网发布状态见[更新清单](https://digimonlegend.com/continuation-updates/latest.json)。
