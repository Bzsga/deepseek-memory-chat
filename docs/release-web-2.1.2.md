## 后台生图

生成任务在服务器独立运行，页面离开、连接中断或 WebView 被销毁后仍能继续。前端先持久保存请求标识，再提交任务，重新进入后按同一标识查询和领取结果。重复查询和幂等确认不重复派发、不增加调用次数；用户明确停止才取消任务。

任务元数据持久保存，提示词仅在进程内存使用并保存摘要。生成结果在服务器私有目录暂存 24 小时，到期清理，领取限任务所属账户。服务重启使未确认的任务变为结果未知，保留记录且不自动重放。
