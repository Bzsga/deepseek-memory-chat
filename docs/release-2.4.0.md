# DeepSeek 记忆聊天 2.4.0

2026-11-18 发布网页、统一后端和 Android 2.4.0（versionCode 34）。

注册无总人数上限。新账号可在同一服务设置中填写个人 DeepSeek Key 或兑换一次性邀请码。注册时也可直接填邀请码。已有注册账号在首次迁移时保留免费资格，管理员可在注册用户列表逐个取消。撤销保留账号和聊天记录，之后的托管模型调用需要重新取得资格。生图使用站长配额，个人 Key 聊天直接向 DeepSeek 请求。

[获取官方 API Key 的图文教程](https://digimonlegend.com/deepseek-api/api-key-guide)共三个步骤，六张配图按需展开。Android 原生整理和网页聊天各自保管个人凭据。原生自定义服务地址、模型和连接测试收进展开项，网页后台将少用的账号操作收进菜单。

## 验证与发布

- 后端合成测试覆盖无邀请码注册、同码并发兑换、老账号迁移和重启后的撤销状态，以及撤销后聊天、文件、语音、生图和原生整理的派发拦截。历史金额邀请码公开兑换入口已退役。
- 网页生产构建在真实 Edge 的 360px、1160px 宽度上，以模拟接口验证邀请码失败、成功、资格刷新与个人 Key 保存。Android 签名构建与 60 项定向 JVM 测试通过。本轮未用真实个人 Key 产生模型请求，未在实体安卓手机上走完整流程。
- 网页和后端部署为 `20261118T051321Z-565003`。公网健康、注册、管理页面、教程与六张图均已核对，生产原有注册账号的免费资格已全部保留。
- Android 安装包已验证包名、版本、证书，并在公开更新频道完整回下载比对 SHA-256。下载入口指向 code 34。回执为 `build/deployment.json`、`build/verified-release-2.4.0.json` 和 `build/public-verification-2.4.0.json`。
