# 2.0.1 / Android 29

2026-11-17，修复未登录首页、聊天导航和旧服务升级入口。2.0.1 / versionCode 29 已部署并发布到现有在线更新通道。上版发行事实保留在 [2.0.0](release-2.0.0.md)。

## 使用变化

- 聊天页全屏显示基于 DeepSeek 官方 chat-demo 的欢迎语、输入框和侧栏，不再叠加原生聊天顶栏与底部导航。未登录也能打开首页；欢迎页和会话页均可开启新对话，发送消息前需要登录。
- 访客首页不初始化账户 runtime、不访问账户本地数据库，也不调用模型。未登录的记忆续聊交付返回失败确认，不创建虚构访客会话。
- 侧栏保留网页“聊天设置”，并提供原生“记忆”“管理账号”“应用设置”入口；浏览器中的记忆与应用设置入口说明 App 用途。
- 仅迁移已停用的官方 `https://digimonlegend.com/continuation-api` 和 `/continuation-api/v1` 服务基址（含可规范化的尾斜杠），清理其失效凭据并提示重新登录。自定义服务不变；原文、记忆、已完成分段和任务设置快照保留，不自动重发旧任务。
- HTTP 410 按请求语境处理：整理任务结果到期可提示确认后重建；已停用服务地址则提示更新地址，不误报为结果过期。
- 稳定下载入口按已发布清单动态选择对应版本的 APK，清单或文件异常时返回暂不可用；不固定跳转到 2.0.0 包。

- 独立截图盲审覆盖手机首页、展开侧栏与桌面首页，未发现阻断交付的视觉缺陷。其结论限于截图，不代替交互或设备键盘验证。三张原始截图保存在私有 `build/qa/2.0.1/`。
