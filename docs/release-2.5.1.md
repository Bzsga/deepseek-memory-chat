# DeepSeek 记忆聊天 2.5.1

Android versionCode 37，网页和后端版本 2.5.1。

- 开启多端同步后，同账号设备可共享语言、主题、朗读音色、深度思考、搜索和侧栏偏好。位置与服务商凭据继续按各自设置管理。
- 在「设置 → 数据管理」的同步区域，可为个人 DeepSeek API Key 单独设置恢复口令。在其他设备登录同一账号，输入口令后恢复并启用个人 Key。服务器保存经过客户端加密的备份。更换 Key 后可手动更新备份。清除云端数据也会删除这份备份。
- 手动同步耗时较长时显示进度，完成后提示结果。保存个人 Key、兑换邀请码和导入聊天备份也提供操作反馈。
- Android 更新提示精简为版本信息和操作按钮。“稍后”选择按版本保存在当前设备，完整更新说明和手动检查位于关于页。

已完成正式签名核验、更新频道发布及公网 APK 全量哈希验证。双 Edge 上下文使用合成账号和模拟接口验证主题同步、加密备份、正确和错误口令以及操作提示。后端账号隔离与云端清除经本地接口测试。未使用真实个人 Key 调用模型，未在实体手机安装本版。
