# 2.1.0 发行记录

Android / 网页 / 后端 2.1.0 已于 2026-11-17 发布，Android versionCode 30。网页与后端先部署，APK 随后通过原有在线更新通道发布。

## 改动

- 聊天输入区增加拍照、相册和文件面板、可移除预览，以及独立生图模式；顶部与侧栏重新整理，保留随时新建聊天。
- 同一会话自动管理上下文，默认软预算 64K，支持查看、编辑、固定和关闭记忆；保留全部原文与分支。每次发送最多增加一次原文片段整理请求，显示活动并正常计次，不自动重放不确定请求。
- 大段续聊背景也按预算选材，避免历史持续增长后每次无界附带。长会话先显示最近消息，可向前加载并保留阅读位置。
- 会话可导出 Markdown、TXT、JSON 或 ZIP；结构化格式保留分支、图片、续聊背景和记忆。全库 ZIP 继续保留。
- 网关在上传前核对真实图片格式与大小；支持无扩展相机图片。生图错误显示安全具体原因，避免全部变成“服务器繁忙”。
- Android 使用受限 FileProvider 调起外部相机，系统保存窗口支持新增会话文件类型，保留同包名、签名与在线更新通道。
