## 聊天、记忆与设置

- **聊天**：访客可用个人 API 聊天。点发送时若缺少配置，会直接打开「聊天 API」窗口并保留草稿。本机访客资料和各账号资料分开保存。附件面板提供拍照、相册和文件，选中后可预览与移除。普通对话可按明确的绘图请求调用生图工具，图片显示在当前回复。长会话分批显示较早消息，原文持续保存在当前设备。
- **自动续聊**：保持同一会话，自动选取近期对话、相关旧原文和长期记忆。需要时整理一个尚未处理的原文片段，状态与额外调用可见。会话菜单可查看、编辑、固定或关闭记忆，也能导出当前会话。
- **分享 ZIP 到 Android**：安装 2.6.1 后，从文件管理器将 DeepSeek 官方导出的 ZIP 分享给本应用。若出现确认条，点「导入」。完成后会打开聊天列表，可以选择任一会话继续聊。再次导入同一份 ZIP 会保留已有的续聊记录。
- **记忆**：导入 DeepSeek 分享链接、ZIP/JSON 或粘贴文字；短会话可直接保留原文，无需模型。智能整理尽量保留原话、来源、讨论理由和未定事项，可编辑、固定、补入最近聊天或批量删除档案。
- **设置**：聊天侧栏与 Android 底栏共用设置中心。通用设置集中管理偏好和 API，数据管理区分聊天资料与本机记忆，关于页提供应用信息和 Android 专属操作。管理员也可从开发者入口或网页后台调整用户与额度。

普通聊天会自动管理上下文并保留全部本机原文，记忆带来源。应用按当前 DeepSeek 1M 窗口采用 936,000 的保守估算输入预算，给回复与协议预留 64,000；旧会话的 32K/64K/128K 档位同步迁移，普通界面直接使用自动策略。实际输入更多时上游 token 消耗可能增加，额度按实际调用次数计算，自动整理的额外请求同样计次。分支或原文变化后不继续注入失效记忆。选材与摘要仍可能遗漏细节。

新对话页可通过分享链接续聊，支持 DeepSeek 官方和本应用的公开分享，先查看范围和消息预览，再确认新增会话。图解说明如何从官方 App 选择分享范围并复制链接。本应用分享可一并导入图片，官方分享中缺失的附件原件需要重新上传。

Android 12 及以上聊天页对接系统滚动截图，截图范围为当前已加载的消息区，固定标题与输入栏不重复拼接。较早记录可先在聊天中加载。截图结束或取消后恢复原阅读位置。厂商截图工具的兼容性仍取决于设备实现。

原生记忆工作流继续保留，适合导入外部聊天、维护独立档案或导出给其他应用。手动整理只取所选分支的用户原话和助手正文，先导入本机并进入准备页，明确开始后才请求模型。

记忆结果中的“在这里继续聊”会新建本地聊天，把当前完整续聊材料存为独立背景。它不会冒充已发送消息，也不会自动向模型提问；输入下一句话后才调用模型。复制、保存文件并转到外部 DeepSeek 的方式仍可用。详见[续聊功能说明](docs/conversation-continuity.md)。

## 账户和每周额度

配套聊天和免费智能整理使用同一账户、同一个每周剩余次数，**北京时间每周一 00:00 刷新**。每次实际发往上游的可计次请求消耗一次；聊天、自动上下文整理、原生整理、附件上传、语音识别、朗读和生图共用额度。需要自动整理时，一次发送最多增加一次模型请求。已派发的失败或结果不确定请求仍计次，不自动重放不确定请求。

管理员开放自助注册时，使用用户名和密码即可创建具备基础云同步资格的账号。一次性邀请码可在注册时填写，也可在符合条件的账号中兑换，以获得邀请码配置的权限。管理员可分别调整账号的配套聊天 API、配套生图 API 和云同步，也可以设置默认额度、个人每周上限或本周剩余。已有账号的权限在升级时沿用。

使用自备 API、本机记忆与会话、查看公开分享无需注册。在「账号与同步」或「多端同步」中可按需登录，也可把本机访客会话复制到当前账号。使用配套服务或开启多端同步需要账号具备对应权限。创建和管理公开分享的入口暂时隐藏，已有链接仍可查看，登录后可把本应用的分享会话导入为续聊。

本地导入、查看、编辑、原文接续、备份和导出不扣次数。自 Android 2.6.2 起，新建记忆整理任务直接使用聊天 API。选用个人 API 时，手机直连同一服务地址和模型，由该服务商计费。选用配套服务时，使用同账号的免费周额度。已有任务按创建时的配置继续。

聊天设置可切换配套服务与个人 API。个人模式默认使用 DeepSeek Flash，可在高级设置弹窗更换模型服务地址和模型。Key 按应用账号加密保存在当前设备。回复语气支持预设和自定义，默认沿用模型语气。深度思考时可选思考强度，关闭时可调温度。生图可使用个人接口，也可凭生图权限使用已启用的配套服务。详情见[个人 API](docs/personal-deepseek.md)。

升级时只把已停用的官方旧服务地址迁移到统一服务，并要求重新登录；自定义服务地址不变。原文、记忆、已完成分段和任务快照保留，旧任务不会因迁移而自动重发。远端整理结果到期与服务地址停用（HTTP 410）分别提示。

## 图片与本地资料

生图服务可用时，聊天输入区显示「画图」。可以用文字生成图片，也可以通过「参考图」加入最多 4 张 JPG、PNG 或 WebP（每张最多 12 MiB，合计最多 24 MiB），填写修改要求后发送。打开聊天中的图片也可以点「编辑此图」。编辑结果会作为新图保存，可继续在新图上编辑。

使用配套服务时，每次实际派发生图或编辑请求消耗一次共用额度。任务在服务器后台执行，切屏或页面重建后按原任务取回，重复查询和确认不额外计次。结果在私有目录临时保留 24 小时，取回后保存到本机，可另存系统文件并随聊天 ZIP 备份恢复。模型不会自动看到先前生成的图片，需要看图时应显式添加附件。

普通聊天可以直接提出具体画图要求，由模型调用已配置的生图服务，通常包含聊天与生图各 1 次。只询问能否生图时先了解绘图需求。模型生图动作的原始记录与实际提示词保存在本机及结构化备份中，生成完成后的历史会标明结果与实际提示词。

生成图和上传图可点击进入全屏预览，双指、双击或滚轮缩放，拖动查看。长按或右键打开图片菜单，Android 选择“保存到相册”会把原图写入 `Pictures/DeepSeek/`，完成后提示“已保存到相册”。Android 8/9 首次保存按需申请存储写入权限。浏览器版本使用浏览器下载功能。

会话菜单可导出 Markdown、纯文本、JSON 和 ZIP，也可选择“先智能整理”进入原生准备页，再决定使用原文或智能整理。Markdown/文本适合阅读当前选中分支；JSON/ZIP 保存完整分支树、图片原件、续聊背景和长期记忆，可用聊天资料导入恢复。其他附件仅保留元数据。JSON 最多 32 MiB，更大资料请使用 ZIP；全库 ZIP 备份仍保留。

有云同步权限的账号可在「设置 → 数据管理」开启多端同步，按需选择聊天记录、聊天偏好及图片与附件原件。个人 Key 可在「同步设置」中手动加密备份。关闭同步或撤回权限会暂停上传和读取，登录后仍可清除既有云端副本，本机内容保留。并发编辑保留两份会话。同步使用 0 次模型额度。详见[同步说明](docs/conversation-sync.md)。

Android 记忆资料与聊天 WebView 使用各自的本地数据库，备份入口分别管理。原生独立记忆档案使用原有备份方式。卸载、清除应用数据或清理浏览器存储前，可分别备份。记忆备份保存原始导入与档案，不包含密钥和账户会话。

聊天请求由统一后端转发，后端保存无正文的调用/额度记录与附件归属。后台生图临时保留生成结果 24 小时以供切屏恢复，提示词仅在进程内存中使用并保存摘要。智能整理任务为恢复进度而短暂保存选定内容和结果，并有到期清理及可关闭的私有失败诊断。完整范围见[隐私说明](docs/privacy.md)。
