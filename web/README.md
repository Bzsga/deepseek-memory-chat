# DeepSeek 记忆聊天：网页端

React / TypeScript 聊天前端，版本 2.6.0，既可在浏览器使用，也作为 Android WebView 的聊天页。整体入口见[根 README](../README.md)，跨模块约定见 [merge-contract.md](../docs/merge-contract.md)。

## 开发与构建

使用 Node.js 22+ 和 pnpm：

```text
pnpm install --frozen-lockfile
pnpm dev
pnpm type
pnpm lint
pnpm build
```

开发端口 8090，产物在 `dist/`。正式网页路径为 `/deepseek/`，API 默认 `/deepseek-api/chat`。未登录时打开本机访客工作区。访客可使用自己的 DeepSeek API Key 聊天，聊天记录及 Key 与登录账号分别存储。托管免费服务、云同步和创建公开分享需要登录。网页聊天使用同源后端登录 Cookie，开发服务本身不提供账户或模型服务。无需依赖旧工程的 `node_modules`。

Android 支持 WebView 105 起，视口默认高度使用兼容的 `vh`；移动端 hook 测量实际高度并忽略 0 或非有限读数，原生布局切换中保留上次有效尺寸。修改此链路时应检查首次加载、失焦、视口缩放及零读数，不能只凭正常尺寸截图判断。2.0.2 属于网页在线修复，不提高 APK 版本，见[修复记录](../docs/release-web-2.0.2.md)。

## 数据与账户

会话和图片原件保存在当前注册账户对应的 IndexedDB 中。设置中的数据管理提供默认关闭的多端会话同步，同账号开启后将会话与可用附件原件上传私有服务。关闭后暂停同步并保留云端，单独清除云端会话会同时关闭同步，本机保留。协议、并发与留存见[同步说明](../docs/conversation-sync.md)。切换账户不会把历史带给另一个账户；清理浏览器数据或卸载 APK 会删除对应本地资料。

注册开放。新账号可在设置中填写个人 DeepSeek API Key，或兑换一次性邀请码开通免费服务。个人 Key 填写处提供官方平台图文教程。拥有免费资格时，侧栏显示本周剩余次数，按北京时间周一 00:00 刷新。配套聊天、生图、附件上传、ASR/TTS 和记忆整理共用额度，按实际派发计次。个人 DeepSeek 模式下，聊天、文件和语音使用个人账户计费，生图可使用个人接口，也可凭免费资格使用已启用的配套服务。管理员取消资格后，用户可在设置中保存个人 Key 继续聊天。聊天设置中的个人 Key 使用独立本机加密存储，详见[个人 API 说明](../docs/personal-deepseek.md)。Android 内账户入口交回原生页面，浏览器使用后端登录/注册页。

手机顶部在欢迎页和会话页始终保留“开启新对话”。侧栏的“设置”集中管理偏好、API、数据和关于信息；在 App 内，可直接打开对应的本机设置详情。“记忆”和“管理账号”仍通往原生页面。访客登录入口也使用同一原生账户页，浏览器则进入正式登录页。

“数据管理”支持聊天 ZIP 备份和恢复；会话菜单还可导出当前分支的 Markdown/TXT，或包含整个会话树、图片原件、完整续聊背景与长期记忆的 JSON/ZIP。非图片附件仅保留元数据。单会话 JSON 最多 32 MiB，更大资料请使用 ZIP。结构化恢复需确认，成功后替换当前账户的网页聊天资料。它与 Android 原生记忆备份分开管理，均不包含 API Key 或账户密码。

## 自动上下文与原生记忆

普通发送自动使用 936,000 估算输入预算，按当前 1M 模型窗口预留 64,000 回复空间，选择近期完整轮次、相关旧原文和有效记忆，大段 `continuity` 也纳入预算。旧档位读入时迁移。每次发送最多增加一次原文片段整理请求，通过同一账户正常计次。原文持续保留，失败或不确定片段不自动重放。会话菜单提供状态、编辑、固定、删除和关闭记忆。模型的实际上下文仍有限，摘要可能遗漏细节。

欢迎页的分享续聊先调用固定官方地址的同源读取接口，再预览和确认新增本地会话。`sharedSource` 保存公开快照的原始 UTF-8、来源和范围信息，结构化备份保留这些资料。未成对原文按真实角色引用，选取只跟随当前分支。设置的“关于该软件”集中展示作者、QQ、制作和开源说明。

点击回复下方的分享箭头可选择消息创建本应用公开分享，设置中的数据管理可管理并撤销全部自己的分享。统一续聊入口也支持本应用链接，确认前不写账户资料库或下载图片，确认后以一个事务追加原文、来源与验证过的图片。公开链接进入 `?share=` 时先暂存编号，登录后显示预览，用户确认才导入。公开副本的服务器留存与撤销见[会话分享](../docs/conversation-sharing.md)。

`src/services/scrollCapture.ts` 为 Android 12 及以上的系统滚动截图回调提供当前消息区几何和滚动控制。截图暂停自动跟随，结束、取消、切换会话或内容变化时恢复原位置。流式生成、遮挡浮层和缩放状态下不提供截图目标，范围只包括当前已加载的消息。原生回调位于 `ChatScrollCapture.kt`，无需新增 WebMessagePort 协议。

2.3.1 手机会话采用真实 document 滚动，使 WebView 本身提供可滚动范围。顶部与输入框固定，视觉视口收缩时预留键盘遮挡量。`useImageActions` 共用全屏图片预览与原件保存，长按菜单使用 `Modal.requireBackdropPointerDown`，防止开启菜单的旧触摸在松手时生成兼容鼠标事件并关闭新遮罩。

- 原生独立整理工具只导出当前选中分支的用户文字和助手正文，排除思考、工具过程及服务提示；在原生准备页确认后才调用模型。
- “在这里继续聊”接收原生提供的完整材料并新建本地会话，将材料保存为独立背景；写入成功才 ACK，重复交付不会重复建会话，不自动发送消息。
- 浏览器没有原生桥时显示 App 使用说明与 `/deepseek/download` 入口，普通聊天仍可使用。

原生通道只接受正式来源与准确主页路径下的 WebMessagePort，JSON 上限 2 MiB。不要用开发页面放宽生产来源校验，也不要把导入聊天当作可执行指令。入口为 `src/services/nativeBridge.ts` 与 `src/services/chat/continuity.ts`。

构建后可运行 `node scripts/preview-guest.mjs`，在 `http://127.0.0.1:18091/deepseek/` 检查未登录首页。此本地预览固定返回未登录状态，不提供登录或模型服务；不替代 App 原生桥检查。

## 图片生成

runtime 启用后显示“生成图片”。本地先持久保存稳定请求编号，再短请求创建后台任务。切屏、断网、页面销毁后按相同编号查询和领取结果，明确停止才取消远端任务。未确认提交时用户可显式继续同一编号，幂等确认不重复派发。完成图片支持原件下载、本地保存与 ZIP 备份，暂存失败时保留结果供保存重试或导出。

普通聊天通过本轮随机标识绑定的末尾应用动作，由模型根据明确的绘图请求调用生图。只有完整流结束且包含一个有效动作，才持久保存实际提示词与任务编号并提交现有后台任务。控制段在流中隐藏，能力询问先了解需求。手动生图可选 1–5 张，聊天可在一个动作中为每张提供独立描述。配套服务按实际派发的图片逐张计次，聊天请求另计。成功图片单独保存，恢复只读取既有任务。`imageAction.ts` 管理有界原始动作记录，归档保留这些资料，导入仅恢复本机证据。后续模型历史仅在存在真实图片时附上已生成状态与实际提示词。

任务恢复标记只保存在当前账户的 IndexedDB，不写入便携 JSON/ZIP。服务器结果暂存 24 小时，过期或上游结果未知时明确提示。账号变化后按新账户鉴权，旧任务不会串入新账户。

生成图片不会自动作为像素输入传入后续聊天，也不会编造文字描述送入记忆。需要模型看图时应明确添加附件。APK 下载使用普通 Blob 链接，由原生文件保存桥处理。
